# Contributing to FastMart 🚀

Thanks for considering contributing! Follow these steps to ensure a smooth process.

## 📝 How to Contribute

1. **Find an issue**  
   - Check [GitHub Issues](https://github.com/harisalimughal/FastMart/issues) for tasks labeled `good first issue` or `Todo`.  
   - If no issue exists for what you want to work on, [create one first](#-creating-an-issue).

2. **Self-assign the issue**  
   - Assign yourself the issue.

3. **Fork & Clone the Repository**

    - Fork the repository
    - Clone using: 

    ```sh
    git clone <repo-url>
    ```

## ✨ Creating an Issue

Before working on a feature or fix, you must create an issue and wait for a repository contributor to review and accept it.

### Issue format

Each issue should follow this format:

#### Overview  
A brief description of the problem or feature request.  

#### Acceptance Criteria  
- List the expected behaviors or changes.  
- Define success conditions for the implementation.  

#### Testing Requirements  
- How will the feature be tested?  
- What edge cases should be considered?  

#### Dependencies  
- List any related issues or external dependencies (if any).  

### Issue Acceptance

- Once you submit an issue, a contributor will review it.
- If accepted, the contributor will approve it and add the Todo label.
- Only then can you self-assign and start working on it.
